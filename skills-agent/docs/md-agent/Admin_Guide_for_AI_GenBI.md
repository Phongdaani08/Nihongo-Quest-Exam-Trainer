# คู่มือการใช้งานสำหรับผู้ดูแลระบบ (AI_GenBI Admin Guide)

---

## 1. เขียนให้ใครอ่าน

คู่มือนี้เขียนสำหรับ:

- **ผู้ดูแลระบบ (Admin)** ที่ต้องตั้งค่าและดูแลผู้ใช้
- **หัวหน้าทีม** ที่ต้องแชร์รายงานให้ลูกน้องดู
- **ผู้ใช้ทั่วไป** ที่ต้องการเข้าใจฟังก์ชันหลักของระบบ

ใช้ภาษาที่ใครก็อ่านได้ ไม่อธิบายด้วยศัพท์เทคนิคล้ำลึก ถ้าจำเป็นต้องใช้คำทางเทคนิค จะอธิบายความหมายประกอบเสมอ

---

## 2. AI_GenBI คืออะไร ช่วยอะไรได้

AI_GenBI คือ **เครื่องมือช่วยถาม-ตอบข้อมูลด้วยภาษาคน** และ **สร้างรายงานภาพ (Dashboard)** จากฐานข้อมูลขององค์กร

สิ่งทีระบบทำได้:

- คุณถามคำถามธรรมดา เช่น "ยอดขายเดือนที่แล้วเป็นเท่าไร" ระบบจะแปลงเป็นคำสั่งเรียกข้อมูล แล้วเอาคำตอบกลับมาให้
- สร้างกราฟ ตาราง หรือแผนภูมิ จากคำถามนั้นได้ทันที
- เชื่อมต่อหลายฐานข้อมูลเข้าด้วยกัน เพื่อให้ดูข้อมูลได้จากหลายแหล่งในที่เดียว
- ควบคุมสิทธิ์ผู้ใช้ ว่าใครเห็นรายงานไหนบ้าง

---

## 3. วิธีเข้าใช้งานครั้งแรก

### 3.1 เปิดเว็บไซต์

ปกติระบบจะอยู่ที่:

- **หน้าหลักสำหรับเข้าใช้งาน:** `http://localhost:3000` (สำหรับทดสอบในเครื่อง)
- ถ้าเป็นระบบจริงขององค์กร จะใช้ลิงก์ทีแผนกไอทีส่งให้

### 3.2 ล็อกอิน

1. ใส่อีเมลของคุณ
2. ใส่รหัสผ่าน
3. ถ้าระบบถามให้ยืนยันว่าเป็นบัญชีของคุณเอง ให้ทำตามขั้นตอนบนหน้าจอ

### 3.3 หน้าจอหลักหลังเข้ามา

หลังล็อกอิน คุณจะเห็นเมนูด้านข้าง ประกอบด้วย:

- **Chat / ถามข้อมูล:** ถามคำถามเป็นภาษาคน
- **Dashboard / แดชบอร์ด:** ดูรายงานทีสร้างไว้
- **Data Sources / แหล่งข้อมูล:** จัดการฐานข้อมูลทีเชื่อมต่อ
- **Users / ผู้ใช้:** จัดการบัญชีและสิทธิ์
- **Settings / ตัังค่า:** ตัังค่าบัญชีและระบบ
- **Notifications / การแจ้งเตือน:** ดูข้อความแจ้งเตือน

---

## 4. การถามข้อมูลด้วยภาษาคน (Chat)

### 4.1 วิธีถาม

1. ไปทีเมนู **Chat**
2. พิมพ์คำถามธรรมดา เช่น:
   - "ยอดขายรวมปีนี้เท่าไร"
   - "ลูกค้ารายใหญ่ 5 อันดับแรกคือใคร"
   - "ยอดสั่่งซื้อเดือนมกราคมมากกว่าเดือนกุมภาพันธ์หรือไม่"
3. กดส่ง แล้วรอคำตอบสั้น ๆ

### 4.2 คำตอบทีได้รับ

ระบบจะตอบกลับเป็น:

- **ตัวเลข หรือข้อความสรุป** เช่น "ยอดขายรวม 15,420,000 บาท"
- **ตารางข้อมูล** ถ้ามีหลายรายการ
- **กราฟ หรือแผนภูมิ** ถ้าคำถามเหมาะกับการแสดงภาพ
- **คำสั่งเรียกข้อมูล** สำหรับผู้ดูแลระบบที่อยากตรวจสอบว่าระบบทำงานอย่างไร

### 4.3 ข้อควรระวังเวลาถาม

- **ถามชัดเจน:** ระบุชื่อตารางหรือชื่อฟิลด์ถ้าไม่แน่ใจ เช่น "ยอดขายในตาราง sales"
- **อย่าถามคำถามเปิดกว้างเกินไป:** เช่น "บอกทุกอย่างเกี่ยวกับลูกค้า" อาจทำให้ระบบสับสน
- **ตรวจสอบผลลัพธ์:** ถ้าตัวเลขดูผิดปกติ ให้ลองถามใหม่อีกครั้ง หรือขอดูตารางข้อมูล

---

## 5. การสร้างและดู Dashboard (แดชบอร์ด)

### 5.1 Dashboard คืออะไร

Dashboard คือ **หน้ารายงานทีรวบรวมกราฟและตัวเลขสำคัญ** ไว้ในที่เดียว เพื่อให้ผู้บริหารหรือทีมงานดูสถานการณ์โดยรวมได้ง่าย ๆ

### 5.2 สร้าง Dashboard ใหม่อย่างไร

1. ไปทีเมนู **Dashboard**
2. กดปุ่ม **สร้าง Dashboard ใหม่** (หรือ New Dashboard)
3. ตั้งชื่อรายงานให้เข้าใจง่าย เช่น "ยอดขายประจำเดือน"
4. เลือกว่าจะเพิ่มวิดเจ็ต (ชิ้นส่วนแสดงผล) แบบไหน:
   - กราฟแท่ง
   - กราฟวงกลม
   - ตาราง
   - ตัวเลขสรุป
5. พิมพ์คำถามหรือเลือกข้อมูลทีต้องการให้แสดง
6. บันทึก

### 5.3 จัดเรียงหน้า Dashboard

- ลากและวางวิดเจ็ตต่าง ๆ ไปในตำแหน่งทีต้องการ
- ปรับขนาดโดยการลากขอบกล่อง
- ลบวิดเจ็ตทีไม่ใช้ โดยกดไอคอนถังขยะ

### 5.4 แก้ไข Dashboard ทีมีอยู่

1. ไปทีเมนู **Dashboard**
2. คลิกชื่อรายงานทีต้องการ
3. กดปุ่ม **แก้ไข** (Edit)
4. เปลี่ยนแปลงตามต้องการ แล้วกด **บันทึก**

---

## 6. การแชร์ Dashboard ให้ผู้อื่นดู

### 6.1 เชิญผู้ใช้เข้าดู Dashboard

1. เปิด Dashboard ทีต้องการแชร์
2. กดปุ่ม **แชร์** หรือ **เชิญผู้ใช้**
3. ใส่อีเมลของคนทีต้องการเชิญ
4. เลือกสิทธิ์:
   - **ดูได้อย่างเดียว** (View) — เห็นรายงาน แต่แก้ไขไม่ได้
   - **ดูและแก้ไขได้** (Edit) — ช่วยปรับแต่งรายงานได้
5. กด **ส่งคำเชิญ**

### 6.2 ผู้ถูกเชิญจะได้รับอะไร

ผู้ถูกเชิญจะได้รับอีเมลพร้อมลิงก์. เมื่อกดลิงก์ ระบบจะพาเข้า Dashboard โดยอัตโนมัติ โดยไม่ต้องมานั่งหาชื่อรายงานเอง

### 6.3 ความปลอดภัยของการแชร์

- ลิงก์ในอีเมลมีอายุจำกัด (ปกติ 24 ชั่วโมง) หลังจากนั้นต้อง log in ด้วยตัวเอง
- ถ้าต้องการถอนสิทธิ์ ให้ลบชื่อคนนั้นออกจากรายชื่อผู้ใช้ใน Dashboard

---

## 7. การจัดการแหล่งข้อมูล (Data Sources)

### 7.1 แหล่งข้อมูลคืออะไร

แหล่งข้อมูลคือ **ฐานข้อมูลภายนอกทีระบบเชื่อมต่อ** เช่น ฐานข้อมูลการเงิน ฐานข้อมูลลูกค้า หรือฐานข้อมูลยอดขาย

### 7.2 เพิ่มแหล่งข้อมูลใหม่

1. ไปทีเมนู **Data Sources**
2. กด **เพิ่มแหล่งข้อมูล**
3. เลือกประเภทฐานข้อมูล เช่น PostgreSQL, MySQL, BigQuery, Snowflake
4. กรอกข้อมูลจำเป็น:
   - ชื่อเรียก (ให้จำได้ เช่น "ฐานข้อมูลยอดขาย")
   - ที่อยู่เซิร์ฟเวอร์
   - ชื่อฐานข้อมูล
   - ชื่อผู้ใช้และรหัสผ่าน
5. กด **ทดสอบการเชื่อมต่อ** เพื่อให้แน่ใจว่าข้อมูลถูกต้อง
6. ถ้าทดสอบผ่าน ให้กด **บันทึก**

### 7.3 แก้ไขหรือลบแหล่งข้อมูล

1. ไปทีเมนู **Data Sources**
2. คลิกชื่อแหล่งข้อมูลทีต้องการ
3. กด **แก้ไข** หรือ **ลบ**

### 7.4 ข้อควรระวัง

- อย่าเก็บรหัสผ่านแบบง่ายดาย
- ถ้าฐานข้อมูลมีข้อมูลลับ ให้ตรวจสอบสิทธิ์ของบัญชีทีใช้เชื่อมต่อ ควรเป็นบัญชีทีอ่านได้อย่างเดียวถ้าไม่จำเป้นต้องแก้ไข

---

## 8. การจัดการผู้ใช้และสิทธิ์

### 8.1 ผู้ใช้ (Users)

1. ไปทีเมนู **Users**
2. คุณจะเห็นรายชื่อผู้ใช้ทั้งหมด
3. กด **เพิ่มผู้ใช้** ถ้าต้องการสร้างบัญชีใหม่

### 8.2 บทบาท (Roles) คืออะไร

บทบาทคือ **ชุดสิทธิ์สำเร็จรูป** บอกว่าใครทำอะไรได้บ้าง ตัวอย่างเช่น:

- **Admin:** ทำอะไรก็ได้ทั้งหมด
- **Editor:** สร้างและแก้ไข Dashboard ได้ แต่ไม่ใช้สิทธิ์จัดการระบบ
- **Viewer:** ดูรายงานได้อย่างเดียว

### 8.3 การกำหนดบทบาทให้ผู้ใช้

1. ไปทีเมนู **Users**
2. คลิกชื่อผู้ใช้
3. เลือก **บทบาท** ทีต้องการ
4. กด **บันทึก**

### 8.4 การจัดการสิทธิ์เฉพาะทาง (Permissions)

ถ้าต้องการกำหนดละเอียดกว่านั้น สามารถเลือกสิทธิ์เป็นรายข้อได้ เช่น:

- อ่าน Dashboard
- แก้ไข Dashboard
- เพิ่มแหล่งข้อมูล
- จัดการผู้ใช้
- ดูบันทึกการใช้งาน

---

## 9. การตั้งค่าส่วนตัวและระบบ

### 9.1 ตั้งค่าบัญชีตัวเอง

1. คลิกชื่อหรือรูปโปรไฟล์มุมขวาบน
2. เลือก **Profile**
3. แก้ไขชื่อ อีเมล หรือเปลี่ยนรหัสผ่านได้

### 9.2 ตั้งค่าภาษา

1. ไปที **Settings**
2. เลือก **Language / ภาษา**
3. เลือกภาษาทีต้องการ เช่น ไทย หรือ อังกฤษ

### 9.3 ตั้งค่าการแจ้งเตือน

1. ไปที **Notifications**
2. เลือกประเภทเหตุการณ์ทีต้องการให้แจ้ง เช่น:
   - มีคนเชิญเข้า Dashboard
   - บทบาทของคุณถูกเปลี่ยน
   - ระบบมีปัญหา
3. เลือกช่องทาง: อีเมล หรือข้อความในระบบ

---

## 10. การดูบันทึกการใช้งาน (Audit Logs)

### 10.1 Audit Logs คืออะไร

Audit Logs คือ **บันทึกว่าใครทำอะไรกับระบบ** เมื่อไหร่ เช่น:

- ใครเข้าสู่ระบบ
- ใครสร้าง Dashboard
- ใครแก้ไขข้อมูลแหล่งข้อมูล
- ใครเพิ่มผู้ใช้ใหม่

### 10.2 วิธีดู

1. ไปทีเมนู **Audit Logs**
2. เลือกช่วงวันทีต้องการดู
3. กรองตามชื่อผู้ใช้หรือประเภทกิจกรรม
4. ส่งออกเป็นรายงานไฟล์ได้ถ้าต้องการ

---

## 11. ข้อควรปฏิบัติเพื่อความปลอดภัย

### 11.1 บัญชีผู้ดูแลระบบ

- อย่าให้รหัสผ่าน Admin กับคนทั่วไป
- เปลี่ยนรหัสผ่านเป็นประจำ
- ถ้ามีพนักงานลาออก ให้ปิดบัญชีทันที

### 11.2 การเชื่อมต่อฐานข้อมูล

- ใช้บัญชีทีมีสิทธิ์อ่านข้อมูลได้อย่างเดียว ถ้าไม่จำเป้นต้องแก้ไข
- ตรวจสอบว่ามีการเข้ารหัสข้อมูลระหว่างเดินทาง (ใช้ TLS/SSL)
- หมั่นตรวจสอบรายชื่อแหล่งข้อมูลทีเชื่อมต่ออยู่

### 11.3 การแชร์ Dashboard

- แชร์เฉพาะกับคนทีต้องเห็นจริง ๆ
- ตรวจสอบสิทธิ์ก่อนส่งคำเชิญ (ดูอย่างเดียว หรือ แก้ไขได้)
- ถ้าพนักงานเปลี่ยนตำแหน่ง ให้ตรวจสอบสิทธิ์ทีเคยให้ไว้

---

## 12. แก้ไขปัญหาเบื้องต้น

### 12.1 เข้าเว็บไม่ได้

- ตรวจสอบว่าเปิดใช้ VPN หรือไม่ (ถ้าระบบต้องการ)
- ลอง refresh หน้าเว็บ
- ตรวจสอบว่าใส่ URL ถูกต้องหรือไม่
- ถ้ายังไม่ได้ ให้ติดต่อทีมไอที

### 12.2 ถามคำถามแล้วไม่มีคำตอบ

- ลองถามใหม่อีกครั้ง โดยใช้คำง่าย ๆ
- ระบุชื่อตารางหรือชื่อฟิลด์ เช่น "ยอดขายในตาราง sales"
- ตรวจสอบว่าแหล่งข้อมูลเชื่อมต่ออยู่หรือไม่

### 12.3 Dashboard ไม่แสดงข้อมูล

- ตรวจสอบว่าแหล่งข้อมูลออนไลน์อยู่หรือไม่
- ตรวจสอบว่าผู้ใช้มีสิทธิ์อ่านข้อมูลนั้นหรือไม่
- ลองเปิด Dashboard ใหม่ หรือ refresh หน้า

### 12.4 ไม่ได้รับอีเมลเชิญ

- ตรวจสอบกล่องจดหมายขยะ (Spam / Junk)
- ตรวจสอบว่าอีเมลถูกต้องหรือไม่
- ให้ผู้เชิญส่งคำเชิญใหม่

---

## 13. คำถามทีพบบ่อย (FAQ)

**ถาม: AI_GenBI ถามได้ทุกเรื่องไหม?**  
ตอบ: ถามได้ทุกเรื่องทีมีข้อมูลในแหล่งข้อมูลทีเชื่อมต่อ ถ้าไม่มีข้อมูล ระบบจะตอบว่าไม่สามารถหาได้

**ถาม: ใครสามารถสร้าง Dashboard ได้?**  
ตอบ: ผู้ใช้ทีมีสิทธิ์ Editor ขึ้นไป ถ้าเป็นผู้ดูแลระบบจะทำอะไรก็ได้

**ถาม: ถ้าใช้คนเยอะ ระบบจะช้าไหม?**  
ตอบ: ขึ้นกับขนาดฐานข้อมูลและคำถาม ถ้าถามข้อมูลจำนวนมาก ให้รอสักครู่ หรือขอให้ทีมไอทีตรวจสอบทรัพยากรเซิร์ฟเวอร์

**ถาม: ข้อมูลจะหลุดรั่วไหม?**  
ตอบ: ถ้าตัง้ ค่าถูกต้องและให้สิทธิ์เฉพาะคนทีจำเป็น ความเสี่ยงจะต่ำ ควรทบทวนสิทธิ์ผู้ใช้ทุกเดือน
